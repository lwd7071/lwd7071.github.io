# Portfolio Cá Nhân - Lương Viết Vĩ Đông

Dự án Portfolio giao diện chuẩn hiện đại, tối ưu cho GitHub Pages.

## 📁 Cấu trúc thư mục:
- `index.html`: Cấu trúc nội dung portfolio & CV.
- `style.css`: Toàn bộ style giao diện, hỗ trợ Dark / Light Theme, Responsive.
- `script.js`: Xử lý đổi theme (lưu vào trình duyệt), mobile menu và scroll active.
- `avatar.png`: File ảnh chân dung của bạn (chỉ cần copy ảnh vào cùng thư mục này và đặt tên là `avatar.png`).
- `cv.pdf`: File CV dạng PDF để khách truy cập có thể bấm nút "Tải CV".

---

## 🚀 Hướng dẫn đưa lên GitHub Pages trong 3 phút:

### Bước 1: Chuẩn bị Repository trên GitHub
1. Đăng nhập [GitHub](https://github.com).
2. Tạo Repository mới đặt tên là: `<username>.github.io` (Ví dụ: `lwd7071.github.io`) và chọn **Public**.

### Bước 2: Push code lên GitHub
Mở Terminal / PowerShell tại thư mục này và chạy các lệnh:
```bash
git init
git add .
git commit -m "feat: init portfolio"
git branch -M main
git remote add origin https://github.com/<username>/<username>.github.io.git
git push -u origin main
```

### Bước 3: Kiểm tra link trang web
- GitHub sẽ tự động kích hoạt GitHub Pages.
- Sau khoảng 1-2 phút, truy cập: `https://<username>.github.io` để xem thành quả!
